Juniper & Vale · a simulated salon front desk

The agent writes a lovely text. Then the calendar is wrong.

Each model runs a salon's client texting for one simulated day: bookings, reschedules, opt-outs, failed deliveries, owner instructions. We grade the calendar, the follow-up queue, every text sent and the end-of-day report against what actually happened in the sandbox. Nothing reads the model's prose for a vibe check.

Method

How it's graded

Sandbox, not a judge

Tools only refuse physically impossible actions (double-booking a stylist, booking outside hours). Rule-breaking actions go through and are logged, and scheduled follow-ups really fire when the clock passes them. Grading reads the final state and the action log.

Every rule is in the prompt

The grader checks only what the system prompt states: quiet hours in the client's own timezone, opt-outs, privacy, a three-text cap, one retry per failed message, draft-means-draft, pre-authorization, and an honest day report.
